⚡ Key Features

Vortex combines a full-featured Android file manager with advanced local network server protocols and direct cloud storage integrations.

📁

Local File Explorer

Clean, futuristic file browser supporting storage analysis, batch zip/unzip operations, file indexing, and fast search.

📡

Local File Server Hub

Host files straight from your device using local FTP, SFTP, WebDAV, DLNA / UPnP Media Streaming, and browser-based Vortex Beam HTTP.

☁️

Cloud Storage Management

Connect directly to your cloud drives (Google Drive, Dropbox, pCloud) with seamless file transfers and no intermediary servers.

⚡

Near-Drop Wireless Transfer

High-speed peer-to-peer (P2P) file transfers over Wi-Fi Direct and local hotspot without consuming internet data.

☁️ Google Drive Integration & Scopes Disclosure

In compliance with Google API Services User Data Policy, below is the transparent disclosure of how Vortex interacts with Google Drive.

Requested OAuth 2.0 Scope

https://www.googleapis.com/auth/drive

Why Vortex requests this scope: Vortex: File Manager is a full-featured Android file browser and local network server application. This permission is requested exclusively to enable the following user-initiated actions:

  • Allowing users to browse their personal Google Drive folders and files inside the app's unified explorer interface.
  • Allowing users to download and transfer files directly between local device storage and their Google Drive.
  • Allowing users to upload selected files and create folders directly in their Google Drive account.
  • Allowing users to stream audio/video files directly from Google Drive to the built-in media player.
  • Allowing users to export Google Workspace documents (Docs, Sheets, Slides) into standard offline files (DOCX, XLSX, PPTX, PDF).

📥 Data Access Disclosure

Vortex accesses only user account email (for account labeling), file/folder metadata (names, IDs, sizes, MIME types, modification dates), and the binary content of specific files explicitly chosen for upload, download, or streaming.

⚙️ Data Use Disclosure

User data is used strictly for user-facing file manager functions. Google user data is never used for advertising, marketing, analytics, profiling, or training artificial intelligence models.

🛡️ Data Protection Disclosure

All Google OAuth credentials and tokens are encrypted at rest using AES-256 GCM encryption via Android Keystore (EncryptedSharedPreferences). All transmissions are encrypted in transit via direct HTTPS/TLS connections with official Google API servers.

🗑️ Data Retention & Deletion

Cached metadata and credentials remain solely on the device. Tapping "Disconnect" immediately and permanently wipes all OAuth tokens and caches. Users can revoke access anytime at Google Account Permissions.

🛡️ Privacy Policy

Last updated: October 14, 2026 | Developer: Ilham Sugiri (Indonesia)

For the full comprehensive policy, please visit our standalone Official Privacy Policy Page (privacy.html).

1. Overview & Core Principles

Vortex: File Manager (Package: com.vortex.filemanager) is dedicated to protecting your privacy. We believe your files and data belong entirely to you.

2. Zero Data Collection & Analytics

Vortex does NOT collect, harvest, transmit, or sell any personal data.

  • ❌ No third-party advertising SDKs (100% ad-free).
  • ❌ No telemetry or tracking analytics (no Firebase Analytics, Google Analytics, or third-party trackers).
  • ❌ No user accounts or registrations required.
  • ❌ No remote server relays (all servers and transfers operate strictly local or direct P2P).

3. Google API Services User Data Policy Compliance

Vortex's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. All credentials and file metadata are handled on-device with hardware-backed AES-256 encryption.

4. Device Permissions Justification

  • MANAGE_EXTERNAL_STORAGE: Required to browse, organize, host, and transfer files across internal memory and SD cards.
  • INTERNET & ACCESS_NETWORK_STATE: Required to operate local network servers (FTP, SFTP, WebDAV, DLNA), perform local network speed tests, and communicate with official cloud APIs.
  • NEARBY_WIFI_DEVICES & ACCESS_FINE_LOCATION: Required by Android OS solely for Wi-Fi Direct peer discovery in Near-Drop transfers. Physical GPS location is never tracked or logged.
  • FOREGROUND_SERVICE: Keeps background file transfers and local file server hosting active when the app is minimized.
